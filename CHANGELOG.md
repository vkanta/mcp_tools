# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-11-17

### Added
- Initial release of custom MCP tools server
- Text Analysis Tools:
  - `word_count`: Analyze word count statistics
  - `character_frequency`: Analyze character frequency
  - `text_statistics`: Get comprehensive text statistics
- Data Transformation Tools:
  - `json_to_csv`: Convert JSON arrays to CSV
  - `csv_to_json`: Convert CSV to JSON
  - `base64_encode`: Encode text to base64
  - `base64_decode`: Decode base64 to text
- Utility Tools:
  - `generate_uuid`: Generate random UUIDs
  - `calculate_hash`: Calculate cryptographic hashes
  - `timestamp_converter`: Convert between timestamp formats
- TypeScript implementation with full type safety
- Comprehensive documentation and examples
- Example configuration for Claude Desktop
